# Успеваемость ученика

Дипломный проект: экран успеваемости ученика (десктопная и мобильная версии).

## Просмотр

Версия выбирается автоматически по ширине экрана: до 767px — мобильная, шире — десктопная.

Принудительный режим для проверки:

- `?view=desktop` — десктопная версия
- `?view=mobile` — мобильная версия

## Структура

- `index.html` — вёрстка, стили и скрипты
- `assets/` — иконки и изображения
